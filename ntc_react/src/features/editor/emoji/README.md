# Local emoji and symbol catalog

Generated by `node scripts/generate-emoji-catalog.mjs` from the repository root.
The generator uses Unicode Emoji 17.0 `emoji-test.txt` and Unicode CLDR English /
Vietnamese annotations pinned to commit `7d2b9cb11cec08f4d333ad73209deb3df0711c3b`.
Sources: <https://unicode.org/Public/17.0.0/emoji/emoji-test.txt> and
<https://github.com/unicode-org/cldr-json/tree/7d2b9cb11cec08f4d333ad73209deb3df0711c3b>.
The Unicode license is included in `UNICODE-LICENSE.txt`.

4,019 unique strings across 10 groups: fully qualified emoji (including family,
gender and skin-tone variants), plus plain symbols and regional indicator letters.
Entries are grouped by category and store character, English label, Vietnamese
label and a base-36 word-index sequence. `words` contains the shared normalized search words.
No HTML, images, scripts or runtime requests to run.vn are included.

Coverage audit against run.vn on 2026-11-06: all 1,374 distinct valid character
strings extracted from its character grid exist after decoding ZWJ entities,
removing markup/variation selectors and excluding corrupted replacement characters.
The site's “1001” headline is not treated as an exact dataset size. Glyph rendering
depends on the device's fonts; newer Unicode characters may lack a local glyph.
