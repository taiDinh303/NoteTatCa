## Luồng kỹ thuật phụ trợ và kiểm chứng

- Auth refresh/restore và API401: FLOW-005/036; khởi động/wake/preparation: FLOW-010/037.
- Email OTP/reset/change-email: FLOW-001/004/026; chọn Brevo/SMTP là dependency injection, không chứng minh kết nối thật.
- CI backend: `.github/workflows/backend.yml` restore/build/test Release, kiểm docs/config, Docker build rồi upload evidence. Không đồng nghĩa migrate/deploy production.
- CI frontend: `.github/workflows/frontend.yml` bốn shards, npm ci/type/lint/test/build, Playwright Chromium và upload artifacts. Không chạy pipeline này trong đợt đặc tả.
- Bootstrap roles/admin, seed, EF migration và data transfer là thao tác operator có quyền riêng. Đặc tả này không thực hiện hoặc tự cấp quyền chạy các thao tác đó.

Mỗi action được gắn nhóm luồng. Các biến thể legacy có thể khác DTO/status so với v1; phải đối chiếu source controller tương ứng, không suy hai route tương đương hoàn toàn chỉ vì cùng service.
